# Q-One v0.3 — Motion & Icon Expansion

- Integrated Lucide v1.20.0 UMD library for the editor/public profile.
- Added searchable Lucide icon picker for individual content links.
- Added 9 bilingual Arabic/English font families plus system UI.
- Added 19 activity-oriented animated scene templates.
- Added scene speed and scene motion controls.
- Added 9 scroll reveal transitions with duration and stagger controls.
- Added Breathe and Drift continuous motion presets.
- Added automatic dividers between links with 5 visual styles.
- Added manual Divider block that can be inserted and reordered with links.
- Added divider opacity and width controls.
- Updated state schema to v3 with migration from v0.2/local legacy state.
- Public page now renders Lucide icons, activity motion scenes, dividers, and scroll animations from the same saved design state.
